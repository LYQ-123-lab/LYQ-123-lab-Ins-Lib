# 维度清单 — 从文案里看什么

> 分析 raw 文案时的观测框架。每个维度先收集**原文证据**，再归纳结论。
> 结论的成立条件与引用格式见 [[证据规范]]。
> 维度页不预先建立——某一维度积累到足够证据后，才由 Agent 新建 `wiki/<维度>.md` 并链回 [[index]]。

## 1. 表达语气

- 观测：是讲述还是对话？权威感还是平等感？笃定还是留余地？情绪温度（冷静 / 温热 / 激昂）。
- 提取：标记自称（我 / 我们 / 笔者）与称呼读者的方式（你 / 大家 / 各位）；统计判断词的强度（"一定" vs "可能"）。
- 输出：一句话语气定位 + 3 条以上原文佐证。

## 2. 内容结构

- 观测：文章的骨架是"总—分—总""问题—分析—答案""故事—道理"还是"并列清单"？段落如何分层？
- 提取：把每篇拆成段落并标注功能（引入 / 展开 / 转折 / 收束），找跨篇重复出现的骨架。
- 输出：结构模板（可复用于新稿）+ 出现频次。

## 3. 开场方式

- 观测：第一句怎么起？提问 / 场景 / 金句 / 数据 / 直接下判断 / 讲个小故事？
- 提取：逐篇抄录开头 1–3 句，横向比较。
- 输出：常用开场模式清单，每种附真实例子。

## 4. 观点推进

- 观测：论点如何展开？是一步到位还是层层递进？是否先破后立？是否用"表面…其实…"这类反转推进？
- 提取：画出每篇的观点链（A → 因为 → 所以 → 但是 → 结论）。
- 输出：推进套路，标注哪种出现最多。

## 5. 转折衔接

- 观测：段与段之间靠什么接？关联词、过渡句、还是纯语义跳跃？有没有标志性的转折词。
- 提取：统计转折/衔接词（但 / 然而 / 其实 / 不过 / 说到底 / 再看 / 回头看）及其位置。
- 输出：高频衔接词表 + 用法示例。

## 6. 解释方式

- 观测：遇到抽象概念怎么处理？打比方、举例子、拆定义、对比、还是直接下判断不解释？
- 提取：找出所有"解释性"片段，归类手法。
- 输出：偏好手法排序（哪种最常用、哪种从不使用）。

## 7. 案例使用

- 观测：用不用案例？案例来自亲身经历、新闻、书本还是虚构假设？案例放在观点前还是后？篇幅多长？
- 提取：列出所有案例，标注来源类型与位置。
- 输出：案例使用规律（含"不用案例"这一结论，若确实如此）。

## 8. 节奏

- 观测：段落长短配置、句子长短交替、是否用短句制造停顿、是否有刻意重复。
- 提取：统计段落字数分布、最长/最短段、短句（≤15 字）占比。
- 输出：节奏特征（如"长段铺垫后接一句短句收束"），附例子。

## 9. 句式

- 观测：句长偏好；陈述 / 疑问 / 感叹 / 祈使的比例；是否用排比、对仗、四字格；标点习惯（省略号、破折号、问号的使用频率与位置）。
- 提取：逐篇统计，跨篇比较是否稳定。
- 输出：句式画像 + 高频句式模板。

## 10. 用词习惯

- 观测：高频实词、惯用搭配、专业术语密度、书面语 vs 口语比例、是否爱用副词/形容词。
- 提取：词频统计（去停用词后），标记反复出现的特色词。
- 输出：**特色词表**（正向）与**避雷词表**（从不出现或明确反感）。

## 11. 口语化表达

- 观测：是否有口語插入（"说白了""其实吧""你看"）、语气词、省略句、不完整句。
- 提取：标记所有口语痕迹及其出现语境（是通篇口语还是仅在举例时）。
- 输出：口语化程度等级 + 允许的口语清单。

## 12. 结尾方式

- 观测：怎么收？总结升华 / 抛出新问题 / 号召行动 / 金句收束 / 戛然而止 / 回到开头（首尾呼应）。
- 提取：逐篇抄录结尾 1–3 句。
- 输出：常用收尾模式清单。

## 13. 倾向使用 / 避免使用

- 观测：哪些表达反复出现（主动偏好），哪些表达**从不出现**（被动禁忌，需足够样本才敢下结论）。
- 提取：正向词表来自词频；禁忌词表需靠"多篇文章都未出现"来推断，样本不足时只能记为 **[待验证]**，不可写成定论。
- 输出：两张表（爱用 / 不用），每条标注置信度。

## 跨维度：母题与观点

除写法外，还要记录**内容层面**的重复：反复讲的观点、反复用的比喻系统、长期关切的主题。
这类结论单独进入"母题与观点"页，用于日后选题（参见 [[用法]]）。
