# 用法 — 拿风格库干什么

> 这套库的终点不是"描述我的风格"，而是让 Agent 在**选题、构思、写稿、改稿、判别**五个场景里直接用上它。
> 所有引用的结论都必须符合 [[证据规范]] 的置信度要求。

## 调用顺序

1. 先读 [[index]] 看有哪些页面、样本量多大；
2. 读 [[风格画像]] 拿整体定位；
3. 按需要读具体维度页、母题页；
4. 结论不足时（样本不足或维度页缺失）**如实说明**，不要硬套、不要脑补。

## 一、选题

- 查"母题与观点"页：哪些观点讲过多次但从未单独成篇？哪些关切反复出现却没写透？
- 优先推荐：**重复出现 + 尚未充分展开**的组合，这是最像"我"的选题。
- 排除：与已写内容高度重复、或只在某个情境下讲过一次的选题。

## 二、构思

- 套用 [[维度清单]] 第 2 项提炼出的**结构模板**，不要每次另起炉灶。
- 开场从"常用开场模式"里选，结尾从"收尾模式"里选。
- 观点推进用本人惯用的推进套路（先破后立 / 层层递进 / 故事带道理）。
- 需要案例时，按本人案例使用习惯选来源类型与位置。

## 三、写稿

逐项对齐（有证据的项才对齐，没有的不要臆造）：

- [ ] 语气是否符合（自称、称呼读者、判断强度）
- [ ] 结构是否符合常用骨架
- [ ] 开场是否用了本人惯用模式
- [ ] 衔接词是否落在高频词表里
- [ ] 句式长度、标点习惯是否接近
- [ ] 用词是否落在"特色词表"，避开"避雷词表"
- [ ] 口语化程度是否一致
- [ ] 结尾是否用了本人惯用收尾

## 四、改稿

拿到一篇稿子（无论谁写的），按上面的清单逐项 diff，输出三栏：

| 项 | 原稿 | 改成什么 | 依据 |
|---|---|---|---|
| 开场 | 平铺直叙 | 改为提问式 | 【稳定】常用提问开场（[[raw/某篇]]） |

只改**有依据**的地方；没有证据支撑的差异，标注"无风格依据，交给人决定"，不要擅自改。

## 五、判断"这像不像我写的"

给一段文字，输出：

1. **结论**：像 / 部分像 / 不像。
2. **逐项比对**：按维度清单给出命中与偏离，每项注明依据（或注明"该维度暂无证据"）。
3. **最不像的三处**：指出具体位置并给出修改方向。
4. **置信度声明**：本次判断基于 n 篇样本；若 n<3，必须写明"样本不足，结论仅供参考"。

判别的重点在于**说出哪里不像、为什么不像**，而不是给一个模糊的分数。

## 六、素材不足时怎么办

若 `raw/` 为空或样本不足（n<3）：

- 直接告诉人"风格库还没有足够证据，现在下的判断不可靠"；
- 可以照常协助写稿，但**不宣称这是你的风格**；
- 优先催素材：一句话投喂也算（见 [[index]] 使用说明）。
