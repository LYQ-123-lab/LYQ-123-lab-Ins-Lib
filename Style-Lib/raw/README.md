# raw — 历史文案原件

**这里是风格库的唯一事实来源。原文一律不改、不润色、不校对。**

## 放什么

你长期创作的**真实文案**：公众号文章、视频脚本、随笔、笔记、邮件、朋友圈长文、方案…… 只要是你自己写的，越多越好。

## 怎么放

- 一篇一个文件，放本目录下（可按年份建子目录）。
- 文件名建议：`YYYY-MM 标题.md`，便于日后按时间跨度检验风格是否稳定。
- **保留原文**：错别字、标点、口语都别改。被修饰过的文本会污染风格判断。
- 若某篇是 AI 代笔或他人代写，在文件开头加一行 `authorship: 存疑`，Agent 会对其证据降权。

## 不放什么

- ❌ AI 生成但未经你改动的成稿（那不是你的风格）
- ❌ 纯收集的资料、剪藏（那是素材不是你的文字）
- ❌ 模板套用的格式化文案（如固定话术的产品说明）

## 放完之后

说一句"把 raw 里的文案入库"，Agent 会按 [[../wiki/维度清单]] 逐项分析，按 [[../wiki/证据规范]] 判定置信度，把结论写进 `wiki/`，并更新 [[../wiki/index]] 与 [[../wiki/log]]。

之后随时加新文案，Agent 增量更新，不会推倒重来。
