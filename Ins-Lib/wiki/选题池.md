# 选题池

> 本库的**终局产出**：不是"今天看了什么"，而是"接下来可以写什么"。
> 每条灵感单独建页放 `ideas/`，这里只做**工作队列**——管状态、管优先级、管组合。不重复写细节。

## 准入门槛

一条灵感进池必须答得上来这三句，答不上就还不配占位置：

1. **写什么** —— 一句话说清题目
2. **凭什么** —— 至少一条 raw 溯源（来源 + 链接 + 日期），外链写成 `[原文链接](<https://xxx>)`
3. **为什么是现在** —— 时效、争议、还是一直没人答好

只有第 1 条的，是念头，不是选题。先放在下面的「孵化区」观察，攒够证据再升级。

## 状态流转

```
孵化区（证据不足，观察中）
   ↓ 攒够 ≥2 条证据
候选（可写，尚未动笔）
   ↓
进行中（已开写）
   ↓
已发布 / 已弃（写明弃用原因）
```

**弃用也要记原因。** 三个月后又冒出同样的念头时，能看到当初为什么否掉它——这是复利，不是垃圾。

## 组合规则 ← 本库的独有价值

单个来源的信息长不出好选题。真正的选题来自**跨类碰撞**：

| 组合 | 例子 |
|---|---|
| A组内部跨类 | 海外媒介案例 + 国内 AIGC 生产提速 + 消费端反例 → 见 [[ideas/AI音频简报模式能否在中国复制]] |
| A组 × B组（需内在逻辑） | 平台抓取之争 + 反蒸馏争议 + 政策定价 → 见 [[ideas/AI生成内容的授权战]] |
| 政策（B组）＋ 公众争论（B组） | 教育政策 vs 知乎上家长吵翻的点 |
| 案例 ＋ 趋势 | 某公司做法 vs 行业方向 |
| 旧素材 ＋ 新事件 | 三个月前攒的案例 + 今天的新闻，旧素材被重新激活 |

**同类内部组合没有价值**，五条知乎热榜拼不出一个选题。跨组组合只在确有内在逻辑时做，并写明理由（见 [[价值分层]]「关联规则」）。

生成组合时的操作：读 [[index]] 找既有主题，读 `trends/` 找活跃方向，读 [[查询手册]] Q5 挖被遗忘的 raw 素材，然后做交叉。
